# Agents 운영 가이드

이 폴더는 에이전트가 프로젝트 규칙, 반복 작업, 재사용 스킬을 찾는 진입점이다.

## 폴더 역할

```text
.agents/
  README.md       # 이 폴더 운영 규칙
  docs/           # 프로젝트 작업 지침서
  commands/       # 반복 작업용 에이전트 커맨드
  skills/         # 재사용 가능한 외부/로컬 스킬
```

## 배포 스킬

`skills/`의 Git 작업 스킬은 이 저장소를 원본으로 관리합니다. 설치 명령과 사용 예시는 [스킬 안내](skills/README.md)를 확인하세요.

- 전역 설치본이나 플러그인 캐시 대신 저장소 원본을 수정하세요.
- 각 스킬은 개별 설치가 가능하도록 필요한 참고 문서를 자기 폴더에 포함하세요.
- 프로젝트 전용 규칙은 `docs/`에 유지하고 배포 스킬에 섞지 마세요.
