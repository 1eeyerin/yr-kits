`smart-commit`은 현재 작업 중인 Git 변경사항을 관련 있는 내용끼리 묶어 커밋하는 스킬입니다. 여러 기능이나 수정이 섞여 있을 때 독립적으로 설명하고 되돌릴 수 있는 단위로 나눕니다.

## 설치

```bash
npx skills add 1eeyerin/yr-kits --skill smart-commit -a claude-code -g
```

프로젝트별 설치와 업데이트 방법은 [설치 및 업데이트](./installation.md)를 참고하세요.

## 사용

작업할 Git 저장소에서 Claude Code를 열고 호출하세요. 커밋할 기능이나 파일을 함께 지정할 수 있습니다.

```text
/smart-commit 로그인 관련 변경만 의미 단위로 나눠 커밋해줘
```

## 동작 방식

1. 수정·삭제·이름 변경·새 파일과 이미 스테이징된 내용을 확인합니다.
2. 프로젝트 지침과 커밋 훅에서 메시지 규칙을 확인합니다.
3. 요청 범위 안에서 관련 변경을 묶고, 필요한 파일이나 파일의 일부 변경만 스테이징합니다.
4. 최종 diff를 확인한 뒤 커밋하고, 생성된 커밋과 남은 변경을 안내합니다.

프로젝트의 커밋 규칙이 있으면 우선 적용하고, 없으면 `<type>: <summary>` 형식을 사용합니다.

## 확인 사항

- 이미 스테이징된 내용이 요청 범위와 다르거나 변경 범위를 구분하기 어려우면 처리 범위를 확인합니다.
- 커밋 훅이 실패하면 원인을 확인하며, 훅을 우회하지 않습니다.
- 커밋 요청만으로 push나 PR 생성까지 진행하지 않습니다.

커밋한 브랜치로 PR을 만들려면 [create-pr](./create-pr.md)를 사용하세요. 세부 지침은 [스킬 원본](https://github.com/1eeyerin/yr-kits/blob/main/.agents/skills/smart-commit/SKILL.md)에서 확인할 수 있습니다.
