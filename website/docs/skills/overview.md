`yr-kits`의 Skills는 Claude Code에서 커밋과 GitHub PR 작업을 도와주는 스킬 모음입니다.

## Overview

| 스킬 | 설명 |
| --- | --- |
| [smart-commit](./smart-commit.md) | 변경사항을 의미 단위로 나누어 커밋합니다. |
| [create-pr](./create-pr.md) | 현재 브랜치의 변경사항으로 GitHub PR을 생성합니다. |
| [update-pr](./update-pr.md) | 후속 변경을 기존 GitHub PR의 제목과 본문에 반영합니다. |

처음 사용한다면 [설치 및 업데이트](./installation.md)를 확인하세요. 각 스킬 페이지에서 설명과 사용 예시를 볼 수 있습니다.
