`create-pr`는 현재 브랜치의 커밋과 변경사항으로 GitHub PR을 생성하는 스킬입니다. 저장소의 PR 템플릿에 맞춰 제목과 본문을 작성하고 담당자와 라벨을 지정합니다.

## 설치

```bash
npx skills add 1eeyerin/yr-kits --skill create-pr -a claude-code -g
```

GitHub CLI(`gh`) 인증과 대상 저장소 권한이 필요합니다. 준비 사항과 프로젝트별 설치는 [설치 및 업데이트](./installation.md)를 참고하세요.

## 사용

PR을 만들 작업 브랜치에서 Claude Code를 열고 호출하세요. 기준 브랜치를 함께 지정할 수 있습니다.

```text
/create-pr main 기준으로 현재 브랜치의 PR을 만들어줘
```

PR에 포함할 변경은 먼저 커밋해야 합니다. 변경사항을 나누어 커밋하려면 [smart-commit](./smart-commit.md)을 사용하세요.

## 동작 방식

1. 현재 브랜치, PR을 받을 저장소와 기준 브랜치, push할 원격 저장소를 확인합니다.
2. 동일한 PR이 있는지 조회하고, 원격 상태와 전체 커밋·diff를 확인합니다.
3. 저장소 템플릿에 맞춰 제목과 본문을 작성합니다. 템플릿이 없으면 요약·변경사항·테스트 섹션을 사용합니다.
4. 필요한 커밋을 push하고 원격 반영을 확인한 뒤 PR을 생성합니다.
5. 현재 인증 사용자를 담당자로 지정합니다. 저장소에 라벨이 있으면 적합한 기존 라벨 1개를 선택합니다.
6. 실제 생성 결과를 확인하고 PR URL과 검증 결과를 안내합니다.

## 확인 사항

- 동일한 PR이 이미 있으면 기존 URL을 안내합니다.
- 기준 브랜치와 비교한 변경사항이 없거나 같은 저장소의 기준 브랜치에서 작업 중이면 PR을 생성하지 않습니다.
- 원격 브랜치가 앞서 있거나 로컬과 이력이 갈라져 있으면 중단합니다. push가 실패한 경우에도 PR을 생성하지 않습니다.
- 담당자나 라벨 지정만 실패하면 생성된 PR URL과 미완료 항목을 안내합니다.

이미 생성한 PR에 후속 변경을 반영하려면 [update-pr](./update-pr.md)를 사용하세요. 세부 지침은 [스킬 원본](https://github.com/1eeyerin/yr-kits/blob/main/.agents/skills/create-pr/SKILL.md)에서 확인할 수 있습니다.
