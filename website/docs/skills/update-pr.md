---

`update-pr`는 이미 열린 GitHub PR을 현재 브랜치의 최신 변경사항에 맞게 갱신하는 스킬입니다. 리뷰 후 수정한 내용을 반영하거나 PR 설명에 빠진 내용을 보완할 때 사용합니다.

## 설치

```bash
npx skills add 1eeyerin/yr-kits --skill update-pr -a claude-code -g
```

GitHub CLI(`gh`) 인증과 대상 저장소 권한이 필요합니다. 준비 사항과 프로젝트별 설치는 [설치 및 업데이트](./installation.md)를 참고하세요.

## 사용

PR의 작업 브랜치에서 Claude Code를 열고 호출하세요. PR 번호나 URL을 함께 지정할 수 있습니다.

```text
/update-pr 현재 브랜치의 후속 변경을 기존 PR에 반영해줘
```

코드 변경을 반영하려면 먼저 커밋해야 합니다. push할 커밋이 없어도 기존 본문에 누락된 설명을 보완할 수 있습니다.

## 동작 방식

1. 열린 PR의 저장소와 브랜치가 현재 작업 및 push 대상과 일치하는지 확인합니다.
2. 원격 상태를 확인하고 로컬 커밋만 앞서 있으면 해당 PR 브랜치에 push합니다.
3. PR의 최신 본문과 전체 커밋·diff를 비교해 누락되거나 부정확한 설명을 반영합니다.
4. 제목과 변경 성격을 나타내는 라벨은 필요한 경우에만 수정하고, 영역·팀·상태 등 다른 목적의 라벨은 보존합니다.
5. PR이 여전히 열려 있는지와 최신 내용을 다시 확인한 뒤 수정하고, URL과 반영 결과를 안내합니다.

기존 본문의 섹션 순서, 사용자가 다듬은 문장, 체크리스트, 링크와 스크린샷 영역을 보존합니다. 이미 반영된 내용은 중복해서 추가하지 않습니다.

## 확인 사항

- 열린 PR이 없으면 새로 생성하지 않으며, 후보가 여러 개면 대상을 확인합니다.
- 원격 브랜치가 앞서 있거나 이력이 갈라진 경우, 원격 브랜치가 사라진 경우에는 중단합니다.
- push가 실패하면 PR을 편집하지 않습니다.
- 제목·본문·라벨이 이미 요청한 상태라면 불필요한 수정 요청을 생략합니다.

새 PR이 필요하면 [create-pr](./create-pr.md)를 사용하세요. 세부 지침은 [스킬 원본](https://github.com/1eeyerin/yr-kits/blob/main/.agents/skills/update-pr/SKILL.md)에서 확인할 수 있습니다.
